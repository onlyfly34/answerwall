# 在真實的 Windows 電腦上驗證新版本

[English](verify-on-windows.md)

AnswerWall 還沒有在 Windows 上搭配任何真實的廠商 CLI 執行過。CI 只用模擬 CLI 涵蓋 Windows。這份清單就是讓擁有者找出實際情況的方法：在一台真實的電腦上依序走過每一步，只要結果和「預期結果」不同，就記下來。

每一個步驟都已依照它所屬版本的程式碼核對過（按鈕名稱、訊息、設定的位置），而 Windows 應用程式的安裝程式、本機模式與結束流程，也在 CI 的 Windows 主機上搭配模擬 CLI 執行過。還沒有人看過的是：真實的 CLI、真實的帳號、真實的電腦。行為不同就是一項發現；只是用字不同，則是這份文件該修正。

## 需要準備的東西

- 一台可以安裝軟體的 Windows 10 或 11 x64 電腦。
- 你要試用的 CLI 各自的帳號（你自己的）。每一次真實的提問都會用到你的訂閱；下面的提問刻意寫得很短。請先讀[使用你的訂閱](../README.zh-TW.md#使用你的訂閱請先讀這一段)。
- G 部分：一台可以用 HTTPS 連線的 AnswerWall 伺服器（[deploy-docker.md](deploy-docker.md)）。
- H 部分：一支連得到該伺服器的手機。
- I 部分：第二個、較新的版本。I 部分可以等有了再做。

開啟**工作管理員**（Ctrl+Shift+Esc），切到**詳細資料**，在欄位標題上按右鍵，選**選擇欄位**，勾選**命令列**。E 與 F 部分會用到。

## C. Windows 上的 CLI

AnswerWall 尋找 CLI 的方式和終端機一樣：在 `PATH` 的各個資料夾中尋找 `<name>.exe`、`<name>.cmd` 等等。它絕不執行 `.cmd` 或 `.ps1` 啟動檔，而是讀取啟動檔，再啟動它所指向的程式。兩種形式都值得試，因為它們在程式中走的是不同的路徑。

| H1  | 如果伺服器使用 TLS `auto`：把 `answerwall-ca.crt` 放到手機上（在已登入的裝置上從**設定 > 連線安全**下載，再傳到手機），並依照那裡列出的 iPhone 或 Android 步驟安裝。 | 手機的瀏覽器開啟 `https://<你的名稱>` 時沒有警告。                                                                                                                                                    |
| H2  | 用 Safari（iPhone）或 Chrome（Android）開啟伺服器的位址。用一組新的配對碼配對。                                                                                      | 出現回答牆，一次顯示一格，有各格的分頁與一排狀態圓點。                                                                                                                                                |
| H3  | iPhone：**分享 > 加入主畫面**。Android：瀏覽器選單 > **安裝應用程式**（或**加到主畫面**）。                                                                          | 主畫面上出現 AnswerWall 圖示。開啟後顯示 AnswerWall，沒有瀏覽器的網址列。Android 上仍是登入狀態。iPhone 上可能會再出現一次登入頁面，因為安裝後的網頁應用程式可能有自己的 cookie；請用新的配對碼配對。 |
| H4  | 送出一個提問，在格子之間左右滑動。                                                                                                                                   | 回答陸續出現；圓點顯示每一格的狀態。                                                                                                                                                                  |
| H5  | 送出長提問，把手機鎖定一分鐘，再解鎖。                                                                                                                               | 可能短暫顯示「連線中斷，正在重新連線…」；接著回答已經完成或仍在陸續出現。沒有任何東西被取消。                                                                                                         |

## I. 更新提示

需要一個比已安裝版本更新、而且沒有標示為預先發行版本（pre-release）的版本：應用程式會忽略預先發行版本。

| #   | 操作                                                                                   | 預期結果                                                                                                                            |
| --- | -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| I1  | 安裝舊版、並且新版已經發布的情況下，啟動應用程式並等待（或選擇**檔案 > 檢查更新…**）。 | 對話框「有新版本 <新版號>。」詢問是否下載，按鈕為**下載**與**稍後**。沒有你的答覆就不會下載任何東西。                               |
| I2  | 按**稍後**。                                                                           | 應用程式繼續以舊版運作。                                                                                                            |
| I3  | 再次啟動應用程式，按**下載**，然後在第二個對話框按**安裝並重新啟動**。                 | 安裝程式以可見的方式執行（SmartScreen 可能再詢問一次），新版隨後啟動。**設定 > 關於**顯示新的版號。歷史紀錄、預設組合與設定都還在。 |
| I4  | 關閉**設定 > 更新 > 檢查新版本**，結束程式後再啟動。                                   | 沒有提示，也不會向 GitHub 發出請求。                                                                                                |
| I5  | 遠端模式或手機，在**伺服器**更新之後：開啟頁面。                                       | 頁面自行重新載入成新版，或顯示「伺服器已更新。重新載入即可使用新版本。」                                                            |

## J. 解除安裝

| #   | 操作                                                                                      | 預期結果                                                                                                                    |
| --- | ----------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| J1  | 結束 AnswerWall。**Windows 設定 > 應用程式 > 已安裝的應用程式 > AnswerWall > 解除安裝**。 | 解除安裝程式不要求系統管理員密碼（安裝給目前的使用者時）。AnswerWall 從開始功能表與清單中消失。                             |
| J2  | 在檔案總管中開啟 `%APPDATA%\AnswerWall`。                                                 | 資料夾還在，裡面有 `data\`（你的歷史紀錄）與 `secrets.json`：解除安裝刻意保留它們。想清除歷史紀錄的話，請手動刪除該資料夾。 |
| J3  | 在終端機中執行：`claude auth status`、`codex login status`。                              | 兩個 CLI 都還在，也都還是登入狀態。AnswerWall 從頭到尾沒有碰過它們。                                                        |
| J4  | 重做 F2。                                                                                 | 沒有任何 AnswerWall 或 CLI 的程序在執行。                                                                                   |
| J5  | 如果這個應用程式曾與伺服器配對：在另一台裝置上，到**設定 > 裝置**撤銷這台電腦。           | 該項目消失。（解除安裝應用程式並不會通知伺服器。）                                                                          |
