# 隱私

[English](privacy.md)

AnswerWall 儲存了什麼、存在哪裡，以及哪些資料會離開你的機器、送給誰。簡單說：AnswerWall 不替任何人蒐集任何東西。你的提問只會送到你放在回答牆上那些供應商的廠商，不會送給其他人。

## 沒有遙測

AnswerWall 沒有分析、沒有使用統計、沒有當機回報、沒有廣告、沒有自己的帳號系統，本專案也沒有營運任何伺服器。網頁不會從其他網站載入任何東西：它的內容安全政策只允許來自提供該頁面的伺服器的指令碼、樣式、圖片與連線。

## 儲存了什麼、存在哪裡

所有資料都在執行伺服器那台機器的**資料目錄**裡：

| 部署方式                   | 資料目錄                                                |
| -------------------------- | ------------------------------------------------------- |
| 直接在主機上執行伺服器     | `~/.answerwall`，或 `ANSWERWALL_DATA_DIR` 指定的位置    |
| Docker 中的伺服器          | 容器內的 `/data`，對應主機上的一個 volume               |
| Windows 應用程式，本機模式 | `%APPDATA%\AnswerWall\data`（它旁邊還放了什麼，見下文） |
| Windows 應用程式，遠端模式 | 只有連線設定與該伺服器的登入狀態；資料都在伺服器上      |

| 檔案                | 內容                                                                                                                                              |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `answerwall.sqlite` | 每一個提問與每一個回答（含推理文字、token 用量、模型、時間）、預設組合、設定，以及每台已配對裝置的名稱、權杖的 SHA-256 與上次使用時間。沒有加密。 |
| `secrets.json`      | 你為 OpenAI 相容端點輸入的 API 金鑰，以及 TLS `auto` 模式下所產生憑證的私密金鑰。只有執行伺服器的帳號可以讀取。                                   |
| `tls/`              | 產生的憑證（僅 TLS `auto` 模式）。                                                                                                                |
| `work/`             | 每個執行中的格子一個空目錄，格子結束時刪除。`grok` 的提問會短暫以檔案形式放在這裡。                                                               |
| `work.lock`         | 一個空的鎖定檔。                                                                                                                                  |

Windows 應用程式使用資料夾 `%APPDATA%\AnswerWall`：資料目錄 `data\`（上表的檔案，但沒有 `secrets.json`）、它自己的 `secrets.json`（API 金鑰，由 Windows 針對你的使用者帳號加密；無法加密時什麼都不會儲存）、`desktop.json`（本機或遠端、伺服器位址、本機連接埠、更新設定）、`logs\`，以及它視窗的瀏覽器設定檔（遠端模式下包含伺服器的工作階段 cookie）。解除安裝會保留這個資料夾；要移除所有東西，請手動刪除它。

歷史紀錄會一直保留，直到你刪除（**歷史紀錄**頁面的**刪除**），或超過**設定 > 限制**中的上限（預設 1000 次提問或 500 MiB），這時會移除最舊的提問。刪除資料目錄就會移除所有東西。

**絕不儲存、絕不讀取：** CLI 的登入資訊。AnswerWall 不會開啟、複製或查看任何 CLI 的憑證或權杖檔案。它只會詢問 CLI 自己的狀態指令是否已登入，並且只保留「是」「否」或「未知」以及登入的種類。`claude auth status` 印出的電子郵件地址與組織，在任何資料抵達頁面、記錄或資料庫之前就已被丟棄。

**記錄（log）**（伺服器的標準輸出）只包含識別碼、數量與狀態，絕不包含提問、回答、權杖、cookie 或 API 金鑰。第一台裝置的一次性配對碼會寫在記錄裡。

**在你的瀏覽器裡：** 一個指令碼讀不到的工作階段 cookie、語言、你回答牆的排列方式與預設的預設組合，以及頁面本身的快取副本（絕不包含回答或任何其他 API 回應）。

## 會離開這台機器的資料

### 透過 CLI

你按下送出時，AnswerWall 會啟動回答牆上每個供應商的 CLI，並把你的提問交給它。之後由 CLI 以你登入的帳號與它的廠商通訊，適用的是廠商自己的隱私條款。AnswerWall 看不到、也不會更動這些流量。

CLI 送出的不只是你的提問。目前已知的情況：

| CLI      | 除了你的提問之外還送出                                                                                                                                                                                               |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `claude` | **已登入帳號的電子郵件地址與工作目錄的路徑**，由 CLI 附加在每個提問上。已在真實執行中確認；沒有選項可以移除。路徑是 `<資料目錄>/work/<id>`，所以通常包含你的作業系統使用者名稱。另外還有 AnswerWall 的簡短系統提示。 |
| `codex`  | CLI 自己的指示，以及**你的全域 `AGENTS.md`**（如果有的話）。已確認。工作目錄、shell、日期與時區不會送出（那一段已關閉）。                                                                                            |
| `agy`    | 沒有檢驗過。它的工具不受限制，所以模型可以讀取你的使用者讀得到的檔案，並可能把內容送給廠商。                                                                                                                         |
| `grok`   | 沒有檢驗過。請比照 `agy` 看待，在 Windows 上尤其如此。                                                                                                                                                               |

除此之外，每個 CLI 都可能為了自己的用途（登入、更新、診斷）連線到它的廠商。AnswerWall 會在它啟動的執行中關閉 `agy` 與 `grok` 的自動更新，其餘的連線一概不更動。各 CLI 自己的開關請參閱各廠商的文件。

開啟**允許網路搜尋**（`claude`、`codex`）時，模型可能會把它根據你的提問自行擬定的搜尋字串，送到廠商的搜尋服務。

供應商頁面上的檢查（伺服器啟動時，以及你按下**重新檢查**時）會執行每個已啟用 CLI 的版本指令；`claude` 與 `codex` 還會執行登入狀態指令。不會送出任何提問。這些指令是否會連線到廠商，由 CLI 決定。

### 送到 OpenAI 相容端點

每一格：模型名稱、你的提問，以及（如果你有儲存）API 金鑰，送到你輸入的基底網址。檢查時：帶著金鑰請求模型清單。不會送到任何其他位址。

### 送給其他對象

- **版本檢查。** Windows 應用程式可以向本專案在 GitHub 上的 Releases 詢問是否有較新的版本；這時 GitHub 會看到你的 IP 位址與應用程式的版本。可以在**設定 > 更新 > 檢查新版本**關閉。伺服器（Docker 或從原始碼執行）不會發出這種請求。
- **沒有別的了。** 不從別處載入字型、指令碼或圖片。回答中的圖片不會載入，只會顯示成連結；連結只有在你點擊時才會開啟。

## 你的裝置與伺服器之間

提問與回答會在你的瀏覽器（或 Windows 應用程式）與你自己的伺服器之間傳輸。使用純 HTTP 時，網路路徑上的任何人都讀得到，所以除非你明確允許，伺服器會拒絕來自其他機器的純 HTTP 連線；見 [security.zh-TW.md](security.zh-TW.md)。

## 其他人

AnswerWall 是為一個人設計的。任何持有已配對裝置的人，都能看到全部的歷史紀錄，也能用你的帳號送出提問。不要替別人配對裝置。
