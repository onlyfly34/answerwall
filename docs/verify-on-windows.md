# Verifying a release on a real Windows PC

[繁體中文](verify-on-windows.zh-TW.md)

Nothing in AnswerWall has been run on Windows with a real vendor CLI. CI
covers Windows with mock CLIs only. This checklist is how the owner finds
out what actually happens: walk through it in order on a real PC, and write
down every step where the result differs from "Expected".

Every step was checked against the code of the release it ships with
(button names, messages, where a setting is), and the Windows app's
installer, local mode and shutdown run in CI against mock CLIs on a hosted
Windows runner. What has not been seen is a real CLI, a real account and a
real PC: a difference in behaviour is a finding; a difference in wording is
a fix to this page.

## What you need

- A PC with Windows 10 or 11, x64, where you may install software.
- Your own accounts for the CLIs you want to try. Every real ask uses your
  subscription; the prompts below are tiny on purpose. Read
  [Using your subscriptions](../README.md#using-your-subscriptions-read-this-first)
  first.
- For part G: an AnswerWall server reachable over HTTPS
  ([deploy-docker.md](deploy-docker.md)).
- For part H: a phone on a network that can reach that server.
- For part I: a second, newer release. Part I can wait until there is one.

Open **Task Manager** (Ctrl+Shift+Esc), go to **Details**, right-click a
column header, choose **Select columns** and tick **Command line**. You will
need it in parts E and F.

## A. Download and install

| #   | Do                                                                                                                                                                                                          | Expected                                                                                                                                                                                                                                                                                                                         |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A1  | Open the [Releases page](https://github.com/onlyfly34/answerwall/releases). Download the Windows installer (`answerwall-desktop-<version>-windows-x64-setup.exe`) and `SHA256SUMS` from the newest release. | Both files are listed, next to `latest.yml`, the installer's `.blockmap` and the server bundle. The release is not marked as a draft.                                                                                                                                                                                            |
| A2  | In PowerShell, in the download folder: `Get-FileHash .\<installer>.exe -Algorithm SHA256`. Open `SHA256SUMS` in Notepad.                                                                                    | The hash matches the line for the installer (letter case aside).                                                                                                                                                                                                                                                                 |
| A3  | Open **Windows Security > App & browser control > Smart App Control settings** and note whether it is On, Evaluation or Off.                                                                                | If it is **On**, the installer will be blocked with no way to allow it: the build is unsigned. Write that down and stop here on this PC, or decide whether to turn Smart App Control off (it affects the whole system).                                                                                                          |
| A4  | Double-click the installer.                                                                                                                                                                                 | SmartScreen shows "Windows protected your PC". **More info** shows the file name and "Unknown publisher". **Run anyway** starts the installer. It shows the MIT licence, then offers to install for the current user (selected) or for all users. For the current user it installs without asking for an administrator password. |
| A5  | Finish the installer.                                                                                                                                                                                       | AnswerWall is in the Start menu. For the current user it is installed under `%LOCALAPPDATA%\Programs`.                                                                                                                                                                                                                           |

For a CLI that is not installed: **Installed: No** and the hint "`<name>` was not found on PATH." The hints under a provider stay in English (they come from the server).                                                                                                                                                                                           |

## C. The CLIs on Windows

AnswerWall finds a CLI by searching the folders of `PATH` for `<name>.exe`,
`<name>.cmd` and so on, the way a terminal would. It never runs a `.cmd` or
`.ps1` launcher: it reads the launcher and starts what it points to. Both
forms are worth trying, because they take different paths through the code.

| #   | Do                                                                                                                                                                                                                                                                                                                 | Expected                                                                                                                                                                                                                                                                                                                                                                                                               |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| C1  | Install `claude` with the vendor's native installer, in PowerShell: `irm https://claude.ai/install.ps1 \| iex` ([official instructions](https://code.claude.com/docs/en/setup)). Open a new terminal: `where.exe claude`.                                                                                          | A path ending in `\.local\bin\claude.exe` inside your user profile. This is the **native `.exe`** case.                                                                                                                                                                                                                                                                                                                |
| C2  | Install `codex` with npm (needs Node.js): `npm install -g @openai/codex` ([official instructions](https://developers.openai.com/codex/cli)). New terminal: `where.exe codex`.                                                                                                                                      | Paths in npm's global folder (by default `%APPDATA%\npm`), among them `codex.cmd`. This is the **npm launcher** case: AnswerWall will start `node.exe` with codex's script, not `codex.cmd`.                                                                                                                                                                                                                           |
| C3  | Quit AnswerWall completely and start it again (a running app does not see a changed `PATH`). **Providers > Refresh all**.                                                                                                                                                                                          | Claude and Codex: **Installed: Yes** with a version number. **Logged in: No** with "Not logged in. Run `claude auth login` in a terminal." (and the same for `codex login`). If a CLI is still "not found", sign out of Windows and in again, retry.                                                                                                                                                                   |
| C4  | If Codex says "`codex` was found on PATH but could not be started": write down the output of `where.exe codex` and `where.exe node`.                                                                                                                                                                               | Not expected. It would mean the launcher could not be reduced to a program, for instance because `node.exe` is in neither the launcher's folder nor `PATH`.                                                                                                                                                                                                                                                            |
| C5  | On the Claude card press **Open a terminal to log in**. (If it says no terminal could be opened: press **Copy the login command**, open a terminal yourself and paste.)                                                                                                                                            | A terminal window (Windows Terminal if it is installed, otherwise a console window) opens and runs `claude auth login`. The page says "A terminal window was opened. Log in there, then press Refresh." The sign-in happens in your browser and in that terminal. AnswerWall's own window never asks for a password or a code. Close the terminal when the CLI says you are logged in.                                 |
| C6  | Do the same for Codex (`codex login`).                                                                                                                                                                                                                                                                             | As C5.                                                                                                                                                                                                                                                                                                                                                                                                                 |
| C7  | Press **Refresh** on each card.                                                                                                                                                                                                                                                                                    | **Logged in: Yes**. **Billing source: Subscription login**. Claude: **Streaming: Token by token**, "Tool access: tools are switched off for every question." Codex: **Whole messages**, a read-only sandbox, and a hint listing what cannot be removed.                                                                                                                                                                |
| C8  | Optional, if a variable such as `ANTHROPIC_API_KEY` or `OPENAI_API_KEY` is set in your Windows environment: read the hint on that card.                                                                                                                                                                            | "Not passed to the CLI: <names>. Turn on "Use the API key from the server environment" to bill those instead of the CLI's own login." Billing source still shows the subscription.                                                                                                                                                                                                                                     |
| C9  | Optional: also try `claude` installed through npm (`npm install -g @anthropic-ai/claude-code`) on a PC without the native install.                                                                                                                                                                                 | `where.exe claude` shows `claude.cmd` in npm's folder. AnswerWall reports it installed and runs it: this is the **npm launcher that points to an `.exe`** case.                                                                                                                                                                                                                                                        |
| C10 | Optional: tick **Enabled** on Gemini (agy).                                                                                                                                                                                                                                                                        | A dialog "Before you enable Gemini (agy)" quotes the vendor's FAQ in English with its source link. **Enable anyway** stays disabled until you tick "I have read this and accept the risk." **Cancel** leaves the provider disabled.                                                                                                                                                                                    |
| C11 | Optional, if `grok` is installed: look at its card.                                                                                                                                                                                                                                                                | **Logged in: Unknown**. Tool access says the tool has no documented way to switch off or restrict its tools (on Windows there is no sandbox).                                                                                                                                                                                                                                                                          |
| C12 | Optional, if `opencode` 2 is installed and has a model configured (see [providers.md](providers.md#opencode-opencode)): tick **Enabled** on OpenCode, press **Refresh**, put an OpenCode cell on the wall and send a short question. Cancel a second one while it is generating, then look for processes as in F2. | **Installed: Yes** with a version 2 number; "Tool access: tools are switched off for every question."; the models of `opencode models` are offered. The answer appears at once when it is finished. After the cancel no `opencode.exe` is left. **Nothing of this has been run on Windows**: write down what differs, in particular a leftover `opencode.exe` (the CLI starts a second process as its private server). |

## D. A first ask

| #   | Do                                                                                                                                             | Expected                                                                                                                                                                                                                                 |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | Open the **Wall**. Remove the cells of providers you did not set up, so that Claude and Codex remain.                                          | The send button reads **Send to 2**.                                                                                                                                                                                                     |
| D2  | Type `Reply with the single word: ready` and press Ctrl+Enter.                                                                                 | Claude: "Waiting for the first words", then the answer, then **Done** with a time and token counts. Codex: "Generating — this provider does not stream token by token", then the whole answer at once, then **Done**.                    |
| D3  | If a cell shows a note or fails, copy its text exactly.                                                                                        | No note is expected. Known unknowns on Windows: a Claude note "The CLI started with extras that this app switches off (…)"; a Codex failure saying it "does not accept one of the switches" or a configuration error (argument quoting). |
| D4  | Send: `請用一句繁體中文回答：「100% 的 A & B」裡的 & 是什麼意思？`                                                                             | Both answers are in readable Traditional Chinese and refer to the `&`. No garbled characters, and no error about the prompt. (The prompt goes through standard input; this checks its encoding.)                                         |
| D5  | Add a cell (**Add cell**), choose Claude and another model, so that three cells use two providers. Send `Count from 1 to 5.`                   | With **Parallel requests** at 2, both Claude cells start at once. All three finish.                                                                                                                                                      |
| D6  | Open **History**.                                                                                                                              | The three asks are listed, newest first. **Open** shows an ask read-only with "Asked on … — read-only". **Ask again** loads its cells and prompt on the wall without sending.                                                            |
| D7  | Optional: on the Providers page turn on **Allow web search** for Claude, then ask `Search the web: what is the newest stable Node.js version?` | The Claude cell shows a note "Searching the web: …" and then an answer. Turn the switch off again afterwards.                                                                                                                            |

## E. Cancel

| #   | Do                                                                                                                              | Expected                                                                                                                                                      |
| --- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| E1  | Send `Write 1500 words about the history of paper.` While Claude is answering, press the cancel button of the Claude cell only. | The Claude cell shows **Cancelled** and keeps the text it had. The Codex cell keeps going.                                                                    |
| E2  | In Task Manager > Details, look for `claude.exe`.                                                                               | Gone within a few seconds.                                                                                                                                    |
| E3  | Send the same prompt again and press **Cancel all** while both cells are busy.                                                  | Both cells show **Cancelled**. Within a few seconds Task Manager shows no `claude.exe`, no `codex.exe` and no `node.exe` whose command line contains `codex`. |
| E4  | Optional: set **Settings > Limits > Time limit per answer** to 5 seconds, send the long prompt, then set the limit back to 300. | Cells that have not finished after 5 seconds show **Timed out**, and their processes are gone as in E2.                                                       |

## F. Quitting leaves no processes

| #   | Do                                                                                                                                                                                                                                                                                                                   | Expected                                                                                                                                                                                  |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| F1  | Send the long prompt from E1 and, while both cells are busy, quit AnswerWall: close its window (or **File > Quit**). The app has no icon in the notification area.                                                                                                                                                   | The window closes and the app ends.                                                                                                                                                       |
| F2  | Within 15 seconds, in Task Manager > Details sort by Name. Or in PowerShell: `Get-CimInstance Win32_Process \| Where-Object { $_.Name -match 'AnswerWall\|claude\|codex\|grok\|agy\|opencode' -or $_.CommandLine -match 'codex' } \| Select-Object ProcessId, Name, CommandLine`                                     | No `AnswerWall.exe`, no `claude.exe`, no `codex.exe`, no `node.exe` running codex. The PowerShell command prints nothing (apart from, possibly, its own line).                            |
| F3  | Start AnswerWall, send the long prompt, and in Task Manager > Details find the `AnswerWall.exe` whose command line has neither a `--type=` argument nor `reaper.cjs` (the main process; the one with `reaper.cjs` is the helper that cleans up after a crash) and end it with **End task** (not "End process tree"). | Within about 15 seconds the other AnswerWall processes and the CLI processes are gone too. This is the case of a crash: the local server notices that the app is gone and stops its CLIs. |
| F4  | Start AnswerWall again and open **History**.                                                                                                                                                                                                                                                                         | The interrupted asks are there. Their unfinished cells are shown as failed or cancelled, not as still answering. Sending a new ask works.                                                 |

| #   | Do                                                                                                                                                                                                                                                       | Expected                                                                                                                                                                                                                                                                                                                                    |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| G1  | Have the server running and reachable as `https://<your name>` ([deploy-docker.md](deploy-docker.md)). If it uses TLS `auto`, install its CA certificate on this PC first (the server's **Settings > Connection security** lists the steps for Windows). | A browser on this PC opens the server's address without a certificate warning.                                                                                                                                                                                                                                                              |
| G2  | In the app choose **File > Connection…**, choose **A server**, enter the server's address and press **Continue**.                                                                                                                                        | The window shows the server's sign-in page: "Pair this device with the server to continue."                                                                                                                                                                                                                                                 |
| G3  | Get a pairing code: on the server run `answerwall pair` (in Docker, inside the container), or on a signed-in device **Settings > Devices > Create pairing code**.                                                                                        | An 8-digit code, valid for five minutes.                                                                                                                                                                                                                                                                                                    |
| G4  | First enter a wrong code.                                                                                                                                                                                                                                | "That code is wrong, was already used or has expired. Create a new code and try again."                                                                                                                                                                                                                                                     |
| G5  | Enter the right code and a device name, press **Sign in**.                                                                                                                                                                                               | The wall appears. **Settings > About** shows **Running as: Server** and the server's version. **Settings > Devices** lists this PC, marked **This device**.                                                                                                                                                                                 |
| G6  | Open **Providers**.                                                                                                                                                                                                                                      | It shows the CLIs of the server, not those of this PC.                                                                                                                                                                                                                                                                                      |
| G7  | Send the long prompt from E1, quit the app while it is answering, start it again.                                                                                                                                                                        | The app opens on the server again without asking for a code. The answer continued while the app was closed and is complete or still arriving.                                                                                                                                                                                               |
| G8  | Ask for an answer that contains a link (`Give me the URL of the Node.js website as a Markdown link.`) and click the link.                                                                                                                                | It opens in your default browser, not inside the AnswerWall window.                                                                                                                                                                                                                                                                         |
| G9  | On another signed-in device, **Settings > Devices**, **Revoke** this PC.                                                                                                                                                                                 | The app returns to the sign-in page at its next action.                                                                                                                                                                                                                                                                                     |
| G10 | On the connection page enter an address that is not an AnswerWall server, then one that does not answer, then (if you have one) a server whose CA is not installed on this PC.                                                                           | The connection page stays open with "Something answered at this address, but it is not a server running AnswerWall.", "The server did not answer. …" and "The server’s certificate is not trusted by this computer. …" respectively. There is no button to ignore a certificate error. The app never shows a blank window you cannot leave. |
| G11 | **File > Connection…**, choose **This computer**, **Continue**.                                                                                                                                                                                          | The local wall and the local history are back, unchanged.                                                                                                                                                                                                                                                                                   |

## H. The phone: installing the page as an app

A phone installs the page as an app only over HTTPS with a certificate it
trusts.

| #   | Do                                                                                                                                                                                                                                           | Expected                                                                                                                                                                                                                                                                  |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| H1  | If the server uses TLS `auto`: get `answerwall-ca.crt` onto the phone (download it under **Settings > Connection security** on a signed-in device and send it to the phone) and install it with the steps shown there for iPhone or Android. | The phone's browser opens `https://<your name>` without a warning.                                                                                                                                                                                                        |
| H2  | Open the server's address in Safari (iPhone) or Chrome (Android). Pair with a new code.                                                                                                                                                      | The wall, one cell at a time, with tabs for the cells and a row of status dots.                                                                                                                                                                                           |
| H3  | iPhone: **Share > Add to Home Screen**. Android: the browser menu > **Install app** (or **Add to Home screen**).                                                                                                                             | An AnswerWall icon on the home screen. Opening it shows AnswerWall without the browser's address bar. On Android it is still signed in. On iPhone it may show the sign-in page once more, because an installed web app can keep its own cookies; pair it with a new code. |
| H4  | Send a prompt, swipe between the cells.                                                                                                                                                                                                      | Answers arrive; the dots show each cell's state.                                                                                                                                                                                                                          |
| H5  | Send the long prompt, lock the phone for a minute, unlock.                                                                                                                                                                                   | "Connection lost. Reconnecting…" may show briefly; then the answers are complete or still arriving. Nothing was cancelled.                                                                                                                                                |
| H6  | Switch the phone to airplane mode and open the app.                                                                                                                                                                                          | The page opens from its saved copy with "This device is offline. …". No old answers are shown from a cache.                                                                                                                                                               |
| H7  | Optional: try `http://<server address>:<port>` (plain HTTP) from the phone.                                                                                                                                                                  | The connection is refused, unless the server was started with `ANSWERWALL_ALLOW_INSECURE=1`, in which case the page shows a red warning about unencrypted connections.                                                                                                    |

## I. The update prompt

Needs a release newer than the installed one that is not marked as a
pre-release: the app ignores pre-releases.

| #   | Do                                                                                                                       | Expected                                                                                                                                                               |
| --- | ------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| I1  | With the older version installed and the newer one published, start the app and wait (or **File > Check for Updates…**). | A dialog "Version <new> is available." asks whether to download it, with **Download** and **Later**. Nothing is downloaded without your answer.                        |
| I2  | Press **Later**.                                                                                                         | The app keeps working on the old version.                                                                                                                              |
| I3  | Start the app again, press **Download**, then **Install and Restart** in the second dialog.                              | The installer runs visibly (SmartScreen may ask again) and the new version starts. **Settings > About** shows the new version. History, presets and settings are kept. |
| I4  | Turn off **Settings > Updates > Check for new releases**, quit, start again.                                             | No prompt and no request to GitHub.                                                                                                                                    |
| I5  | Remote mode or phone, after the **server** was updated: open the page.                                                   | The page reloads itself to the new version, or shows "The server was updated. Reload to use the new version."                                                          |

## J. Uninstall

| #   | Do                                                                                              | Expected                                                                                                                                                               |
| --- | ----------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| J1  | Quit AnswerWall. **Windows Settings > Apps > Installed apps > AnswerWall > Uninstall**.         | The uninstaller runs without an administrator password (for an installation for the current user). AnswerWall is gone from the Start menu and from the list.           |
| J2  | Open `%APPDATA%\AnswerWall` in Explorer.                                                        | The folder is still there, with `data\` (your history) and `secrets.json`: uninstalling keeps them on purpose. Delete the folder by hand if you want the history gone. |
| J3  | In a terminal: `claude auth status`, `codex login status`.                                      | Both CLIs are still installed and still logged in. AnswerWall never touched them.                                                                                      |
| J4  | Repeat F2.                                                                                      | No AnswerWall or CLI process is running.                                                                                                                               |
| J5  | If you paired the app with a server: on another device, **Settings > Devices**, revoke this PC. | The entry disappears. (Uninstalling the app does not tell the server.)                                                                                                 |

## What to write down

For every step that did not match: the step number, what you saw (exact
text; a screenshot without account details), the Windows version
(`winver`), the AnswerWall version, the CLI versions (`claude --version`,
`codex --version`) and how each CLI was installed. Leave out e-mail
addresses, tokens and your user name in paths.
